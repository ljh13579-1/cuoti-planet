# Windows 11 网页桌面

一个使用原生 HTML、CSS 和 JavaScript 编写的 Windows 11 风格网页桌面，完全离线运行，无需安装依赖或构建。

> 本项目仅用于个人学习与演示。界面中的图标、壁纸和插画均为本项目手绘的原创 SVG，不包含微软官方素材。

## 快速开始

直接用 Chrome 或 Edge 打开 `index.html` 即可。

也可以在当前目录启动一个本地静态服务器：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:4173/>。

## 功能

- **锁屏与登录**：锁屏时间、日期、天气，点击或按键进入登录页；演示密码为空，直接按 Enter 即可登录。
- **桌面**：桌面图标、右键菜单、新建文件夹/文本文档、重命名、删除、更换壁纸。
- **开始菜单**：固定应用、所有应用、搜索、推荐项目、电源选项和用户菜单。
- **任务栏**：居中的应用按钮、运行指示、时钟/日期、通知、天气、快速设置。
- **窗口管理**：拖动、最小化、最大化、关闭、边缘贴靠、贴靠布局、任务视图。
- **内置应用**：文件资源管理器、记事本、计算器、终端、设置、照片、天气、回收站。
- **主题与个性化**：浅色/深色主题、强调色、壁纸、任务栏对齐、亮度和夜间模式。
- **本地持久化**：设置和文件内容保存在浏览器 `localStorage` 中，刷新后仍会保留。

## 常用操作

| 操作 | 方式 |
| --- | --- |
| 打开应用 | 点击开始菜单或任务栏图标；双击桌面图标 |
| 搜索 | 点击任务栏搜索图标，或按 `Ctrl + K` |
| 打开终端 | `Ctrl + Alt + T` |
| 锁定屏幕 | `Ctrl + Alt + L` |
| 打开设置 | `Ctrl + ,` |
| 关闭菜单/弹窗 | `Esc` |
| 窗口贴靠 | 拖动窗口到屏幕边缘，或悬停最大化按钮 |
| 重命名/删除桌面文件 | 右键桌面图标 |
| 新建文件 | 右键桌面空白处 |

记事本中按 `Ctrl + S` 保存；终端支持 `help`、`neofetch`、`dir`、`start <应用>`、`theme dark|light` 等演示命令。

## 数据与重置

数据只保存在当前浏览器中，不会上传：

- `win11web.settings.v1`：主题、壁纸、强调色、亮度、音量等设置。
- `win11web.files.v1`：记事本保存过的文件内容。

需要恢复默认状态时，在浏览器开发者工具的 Console 中执行：

```js
localStorage.clear();
location.reload();
```

## 项目结构

```text
win11-web/
├─ index.html          页面骨架、锁屏、任务栏和固定面板结构
├─ css/
│  ├─ base.css         主题变量、桌面、任务栏、锁屏、窗口基础样式
│  ├─ desktop.css      开始菜单、搜索、小组件、通知等浮出面板
│  └─ apps.css         各内置应用与通用控件样式
├─ js/
│  ├─ icons.js         原创 SVG 图标与图标精灵
│  ├─ data.js          设置存储、虚拟文件系统、应用元数据
│  ├─ wm.js            窗口管理器（拖动、缩放、贴靠、任务视图）
│  ├─ apps.js          所有应用的界面与交互
│  ├─ ui.js            桌面外壳、开始菜单、锁屏、任务栏等
│  └─ main.js          启动入口
├─ assets/             原创 SVG 壁纸与站点图标
└─ README.md
```

所有脚本以传统 `<script defer>` 方式加载，不使用 ES Module，因此通过 `file://` 直接打开也能正常运行。

## 浏览器支持

建议使用较新的 Chrome 或 Edge。界面使用了 `backdrop-filter`、CSS Grid、自定义属性等特性，旧版浏览器可能缺少部分视觉效果。
