# 真机验收清单 · 最新版（v1.3.10）

> 本机没有真机也没有模拟器（`adb devices` 为空、CPU 虚拟化不可用），所以这一版所有
> “视觉/触控/性能”结论都没有实机依据。这份清单覆盖 **v1.3.8 的 5 个页面**、
> **v1.3.9 的顶栏 / 返回键** 和 **v1.3.10 的悬浮保存按钮**，加上每次都要回归的 Dock，约 10 分钟。

## 本轮（v1.3.10）三项重点

上机先看这三处，都是本版改动的地方：

1. **顶栏真实模糊**：进入「添加错题」后上下滚动表单——顶栏应该**真的模糊掉身后的输入框/卡片**，
   底边柔和渐隐、没有横向硬线；Android 11 及以下只会是半透明玻璃（没有模糊，属预期）。
2. **返回键**：圆形玻璃，材质与 Dock 一致（中性白/黑底 + 单圈扫光边 + 左上镜面），
   而且应该**透出身后的页面内容**（Android 12+ 有模糊、13+ 有边缘折射）；按下轻微缩小并提亮。
3. **保存按钮（重点）**：
   - 形状是**胶囊**（两头全圆），与 Dock 本体一致，不再是 16dp 圆角矩形；
   - **独立悬浮**在页面底部，下面**不再有一整条深色/黑色的底栏**；
   - 玻璃透出身后表单内容（滚动时能看出内容在按钮后面移动）；
   - 键盘弹出时按钮跟着上移，不遮挡输入框；
   - 滚到表单最底部时，最后一条内容（「我的总结」输入框）能完整露在按钮上方。

## 1. 新增/编辑（改动最大）

- 进入「首页 → 添加错题」或「错题 → 标题右侧 +」。
- 三个区域的小标题（学科、题目、知识点…）应该比旧版更轻、更大间距，不再是粗重标题。
- 只填学科 → 直接点底部「保存错题」：按钮是 54dp 高、16dp 圆角的蓝色主按钮，点击后显示转圈再返回。
- 加一个知识点：标签应该是**浅蓝胶囊**（不是旧版灰底 M3 chip），点它可以直接删除。
- 加图片：缩略图圆角与卡片一致；键盘弹出时底部保存按钮不被遮挡。
- 旋转屏幕 → 表单内容不丢。

## 2. 复习卡片（改动最大）

- 「复习 → 开始复习」进入卡片。
- 顶部进度条应为 **4dp 细条**（旧版是粗条），随题目推进增长。
- 学科以「小圆点 + 文字」显示，难度星星跟在后面。
- 点「显示答案与解析」后：错因 / 解题思路 / 我的总结各自是一张白卡，标题是浅灰小字。
- 三个按钮：不会（白底描边）/ 基本掌握（浅青绿底）/ 已掌握（品牌蓝底），同一高度，小屏不换行、文字不截断。
- 走完全部题目 → 小结页：数字行 + 「返回」主按钮；确认「不会 / 基本掌握 / 已掌握」计数与刚才点的一致。

## 3. 统计（改动较大）

- 「我的 → 学习统计」或首页统计卡进入。
- 概览 4 个数字应是 2×2 排列、中间一条细分割线。
- 学科环形图：中心显示总数，右侧图例每行「学科 · N 道 · 百分比」，颜色与列表里的学科色一致。
- 近 7 天：柱子是**圆角**的，今天实色、其余淡色；柱顶显示次数。
- 难度 / 复习阶段：细圆角进度条（6dp），不是旧版 M3 粗进度条。
- 深色模式下切换一遍：白卡变深灰卡，文字和进度条仍清楚。

## 4. 错题本分类

- 「我的 → 错题本分类」。
- 说明卡 + 分类列表：分类应该合并到**一张卡**里、行间有细分割线（旧版是每个分类一张卡）。
- 右上角 + 号是品牌蓝；新建 / 重命名 / 删除分类都有反应；删除时提示「不会删除错题」。
- 删掉一个分类 → 该分类下的错题回到「未分类」，底部「未分类：N 道」数字随之增加。

## 5. 组卷导出

- 「错题 → 多选 → 组卷」或「我的 → 组卷导出」。
- 范围选择是一张卡；选「按学科」后出现第二排学科胶囊。
- 试卷设置卡：标题输入框 + 两个开关行（包含图片 / 附答案）。
- 「将导出 N 道题」单独一行，数字随范围变化。
- 点「生成 PDF」：按钮显示转圈并禁用；成功后弹窗显示题数、文件名、大小，分享 / 打开 / 关闭都可用。

## 6. 每次都回归的（Dock / 顶栏）

- Dock 在 Android 13+ 是否有玻璃折射、12/12L 是否磨砂、11 及以下是否静态玻璃且不卡。
- 上面 5 个页面顶栏能否模糊身后内容（Android 12+），底边是否柔和渐隐、没有横向硬线。
- 返回键：48dp 触摸区、箭头居中、返回逻辑正确（首页不应出现返回键）。
- 大屏 / 平板：内容最大宽 680dp 居中，不被拉成一整行。
